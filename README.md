## 📖 Обзор проекта

**A-One Disk Analyser** - это настольный инструмент для анализа использования дискового пространства на локальных накопителях или в выбранных папках. Программа позволяет быстро сканировать большие директории, рассчитывать размеры папок и файлов, классифицировать файлы по типу (видео, фото, документы) и визуализировать данные с помощью круговой диаграммы.

Приложение имеет современный пользовательский интерфейс на основе `customtkinter`, поддерживает работу в режиме минимизации в системном трее и обеспечивает удобный просмотр структуры данных в древовидном представлении.

<br>![preview](img/preview.png)

## ✨ Ключевые особенности

* 🕵️ **Глубокий анализ:** Сканирование всех папок и файлов выбранного пути, включая учет размеров на уровне директорий.
* 📊 **Визуализация данных:** Интерактивная круговая диаграмма для отображения распределения занятого места по крупнейшим папкам/типам.
* 🌲 **Древовидное представление:** Удобный иерархический список файлов и папок с указанием их размеров и процентного соотношения от общего объема.
* 🏷️ **Автоклассификация:** Автоматическая классификация файлов по типу (видео, фото, документы) на основе расширения.
* 💾 **Экспорт данных:** Возможность экспорта результатов сканирования в формате CSV.
* 🖥️ **Системный трей:** Работа в фоновом режиме через значок в системном трее Windows/Linux.
* 🎨 **Интуитивный UI:** Современный и адаптивный интерфейс на базе CustomTkinter.

## 📋 Требования (Prerequisites)

Для запуска или сборки проекта вам потребуется установленный Python (рекомендуется Python 3.8+).

### 📦 Зависимости

Проект использует следующие внешние библиотеки:

* `customtkinter`: Для создания современного GUI.
* `Pillow` (PIL): Для работы с изображениями и значком приложения.
* `matplotlib`: Для построения круговой диаграммы.
* `pystray`: Для реализации функции системного трея.
* `tk`: Стандартная библиотека Python для базовых окон и тултипов.

## 🛠️ Установка и настройка (Installation)

Рекомендуется использовать виртуальное окружение (`venv`) для изоляции зависимостей проекта.

### 📥 Шаг 1: Клонирование репозитория

```bash
git clone [URL_ВАШЕГО_РЕПОЗИТОРИЯ]
cd disk-analyzer
```

### 🔧 Шаг 2: Создание и активация виртуального окружения (рекомендуется)

```bash
python -m venv venv
.\venv\Scripts\activate
```

### ⚙️ Шаг 3: Установка зависимостей

Установите все необходимые пакеты. Вам потребуется создать файл `requirements.txt` со списком импортируемых библиотек:

**Содержимое `requirements.txt`:**

```txt
customtkinter
Pillow
matplotlib
pystray
```

Затем установите их через pip:

```bash
pip install -r requirements.txt
```

## 🚀 Запуск приложения (Running)

После установки зависимостей вы можете запустить приложение напрямую:

```bash
python main.py
```

## 🔨 Сборка исполняемого файла (Building the Executable)

Поскольку код содержит логику для работы в замороженном состоянии (`sys._MEIPASS`), проект предназначен для сборки в автономный исполняемый файл (например, `.exe` для Windows). Для этого используется **PyInstaller**.

### 📦 Шаг 1: Установка PyInstaller

```bash
pip install pyinstaller
```

### 🏗️ Шаг 2: Сборка проекта

Для корректной работы приложения при сборке вам необходимо убедиться, что в папке `img/` находится значок `icon.ico`, и все вспомогательные файлы (например, скрипты) доступны.

Используйте следующую команду для создания одного файла-исполняемого файла:

```bash
pyinstaller --onefile --windowed main.py --add-data "image;image"
```

После выполнения команды исполняемый файл будет находиться в папке `dist/`.

## 📁 Структура проекта (Code Structure)

Проект модульный, что позволяет эффективно разделить логику:

* `main.py`: Основной класс приложения (`DiskAnalyzerApp`), управление UI (CustomTkinter), обработка событий и интеграция всех компонентов.
* `scanner.py`: Модуль сканирования диска. Отвечает за рекурсивный обход файловой системы, подсчет размеров папок/файлов и классификацию файлов в многопоточном режиме (`threading`).
* `chart.py`: Ответственен за построение круговой диаграммы с использованием Matplotlib и ее интеграцию в Tkinter.
* `export.py`: Функции для сохранения результатов сканирования (размеры, типы) в структурированный CSV-файл.
